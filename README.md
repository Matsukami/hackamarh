# JREDD+ Tocantins

Ecossistema digital de governança climática para gestão de projetos REDD+ no âmbito do Fundo Climático do Estado do Tocantins.

## Portais

1. **Portal do Proponente**: Submissão de propostas de projetos, monitoramento e prestação de contas.
2. **Portal do Avaliador**: Triagem, Kanban de análise de propostas e validação física-financeira de parcelas.
3. **Portal da Transparência**: Mapa interativo de recursos, beneficiários e impacto ecológico (público).

## Stack Tecnológica

- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Backend/Database**: Supabase (PostgreSQL + PostGIS + RLS + Auth + Storage)
- **APIs**: Anthropic Claude API, Hive Moderation, Evolution API (WhatsApp)
